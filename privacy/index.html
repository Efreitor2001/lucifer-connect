Lucifer Connect / безопасная сеть

Политика конфиденциальности

Редакция от 28 октября 2026 года

Lucifer Connect — клиент безопасной сети. Для использования клиента не требуется создавать аккаунт Lucifer Connect или указывать имя, телефон либо электронную почту. Профили и настройки сохраняются на вашем устройстве.

При подключении и обновлении подписки выбранные вами серверы получают технические данные, необходимые для работы. Ниже объясняется, какие именно данные обрабатываются и кто их получает.

1. О приложении и области действия

Эта политика относится к приложению Lucifer Connect для Android, Windows и Linux и сайту lucifer-connect.ru. Канал проекта для вопросов о конфиденциальности и удаления сведений, отправленных в поддержку, — обращения в репозитории Lucifer Connect.

Клиент позволяет подключаться к собственным серверам или серверам стороннего провайдера по добавленной вами конфигурации. Провайдер подписки, оператор сервера и посещаемые сервисы могут иметь собственные правила обработки данных.

2. Какие данные обрабатываются

ДанныеЗачем нужны и где обрабатываются
Ссылки и конфигурации серверов, ключи доступа, адреса подписок, названия профилейДля импорта, выбора сервера и установления соединения. Сохраняются локально. Данные авторизации передаются выбранному серверу или провайдеру при обращении к нему.
Сетевой трафик, адреса назначения и запросы DNSДля передачи через системный сетевой туннель и применения правил маршрутизации. Обрабатываются на устройстве, выбранным сервером и используемым DNS-сервисом. Исключённые приложения и маршруты обращаются к сети напрямую.
Идентификатор установки, тип устройства, версия системы и версия клиентаКлиент создаёт случайный идентификатор установки и передаёт провайдеру подписки его производное, отдельное для каждого домена, вместе с версией системы. Android-клиент также передаёт модель устройства; Клиенты Windows и Linux указывают тип устройства «PC». Это нужно для совместимости и учёта устройств у провайдера. Аппаратный серийный номер, IMEI и рекламный идентификатор для этого не используются.
Лимиты, расход трафика и срок действия подпискиПриходят от провайдера и сохраняются локально, чтобы показывать состояние подписки.
Выбранные приложения и правила исключенияAndroid-клиент читает список запускаемых приложений для выбора прямого подключения. Выбор хранится на устройстве; клиент не отправляет этот список разработчику или провайдеру подписки.
Состояние соединения, счётчики трафика и диагностические событияДля отображения соединения и поиска ошибок на устройстве. Автоматическая отправка журналов разработчику не предусмотрена.
Текст и вложения, которые вы сами отправляете в поддержкуДля ответа на обращение. При создании обращения на GitHub оно обрабатывается GitHub и может быть публичным. Не прикладывайте секретные ссылки или конфигурации.

Клиент не запрашивает доступ к контактам, фотографиям, микрофону, камере или точной геолокации для работы безопасной сети. Импортированный файл читается только после вашего выбора в системном диалоге. Буфер обмена используется при нажатии на действие вставки.

3. Получатели данных и сетевые обращения

  • Выбранный сервер и провайдер подписки. Получают обращения, данные авторизации и технические сведения, необходимые для подключения или получения подписки. Как и у любого интернет-соединения, принимающей стороне доступен сетевой адрес подключения. Клиент не гарантирует отсутствие журналов на чужих серверах.
  • DNS и проверки доступности. В зависимости от настроек используются выбранные вами DNS-серверы. Проверки соединения могут обращаться к сервисам Google и Cloudflare; они получают технические параметры запроса. Для проверки отдельного профиля запрос отправляется через проверяемую конфигурацию.
  • GitHub. Проверка и загрузка обновлений обращается к GitHub Releases. Сервис получает обычные технические сведения запроса. Данные серверных профилей не включаются в запрос проверки обновлений. См. политику GitHub.

В проверенной версии клиента отсутствуют встроенные SDK рекламы и аналитики. Трафик не перенаправляется для рекламной монетизации, профили и данные соединений не продаются.

4. Разрешения и защита

Android запрашивает ваше разрешение перед созданием системного сетевого туннеля. Постоянное уведомление показывает работу соединения. Доступ к сети нужен для подключения и обновления подписок. Доступ к установке пакетов используется отдельной APK-версией для установки обновления после вашего действия.

На Android профили и адреса подписок хранятся с шифрованием AES-GCM; ключ находится в Android Keystore, системное резервное копирование данных приложения отключено. Windows-клиент защищает хранилище средствами учётной записи Windows. Linux-клиент использует AES-GCM; локальный ключ и файл настроек доступны только владельцу учётной записи. Защита передачи до сервера зависит от протокола и параметров выбранного профиля; используйте конфигурации с шифрованием и доверенных провайдеров.

Linux запрашивает системное подтверждение для создания туннеля и установки проверенных обновлений. Linux-журнал хранит в памяти до 200 событий интерфейса и автоматически не отправляется.

5. Сроки хранения и удаление

  • Профили и подписки хранятся на устройстве до удаления через приложение, очистки его данных или удаления приложения.
  • Настройки, идентификатор установки и правила приложений сохраняются до очистки данных или удаления приложения. Удаление одной подписки не сбрасывает идентификатор установки.
  • Журнал интерфейса Android ограничен последними 100 событиями и хранится в памяти процесса. Временный файл ошибок ядра очищается при завершении соединения; аварийно оставшийся файл заменяется при следующем запуске соединения. Автоматическая передача журналов не выполняется.
  • Загруженные файлы обновлений находятся в локальном кэше. Их можно удалить очисткой кэша или данных приложения.
  • Сведения в обращениях поддержки нужны до завершения обращения; удаление можно запросить в том же обращении. Возможность удаления истории, копий и резервных данных на GitHub определяется правилами GitHub.

Клиент не создаёт центральную учётную запись Lucifer Connect. Очистка локальных данных не удаляет аккаунт или историю у стороннего провайдера: для этого обратитесь к нему отдельно. Подробные действия доступны на странице удаления данных.

6. Данные посетителей сайта

Сайт размещён на GitHub Pages. При открытии страниц хостинг получает технические параметры HTTP-запроса, включая сетевой адрес и сведения о браузере. Главная страница загружает шрифты Google Fonts; применяются правила Google. На страницах документов используются системные шрифты. Сайт не содержит собственных форм регистрации, рекламных трекеров или счётчиков аналитики и не устанавливает собственные файлы cookie. Ссылки на сторонние сервисы открывают ресурсы с их собственными правилами.

7. Обращения и изменения политики

Вопросы по этой политике и запросы об удалении сведений, переданных проекту, можно направить через канал поддержки Lucifer Connect. Публикуйте только несекретное описание запроса. Для обращения необходим аккаунт GitHub; для использования приложения он не нужен.

При изменении обработки данных обновляется эта страница и дата редакции. Если новая функция требует отдельного согласия или разрешения, оно запрашивается в приложении.

English summary

Lucifer Connect is a secure-network client for Android, Windows and Linux. No Lucifer Connect account, name, email or phone number is required. Profiles, subscription URLs and settings are stored locally. Android encrypts profile storage with Android Keystore; Windows uses account-bound protected storage. Linux uses AES-GCM with a local key and owner-only file permissions.

The client processes network traffic and DNS requests to establish the user-selected tunnel and routing rules. Your selected server and DNS provider handle the corresponding requests. Subscription requests include a domain-specific derivative of a random installation identifier, system version and client version. Android also sends the device model; Windows and Linux send the device type «PC». The subscription provider may return quota and expiry information. Third-party servers may have their own logging and retention policies.

Connection checks may contact Google and Cloudflare. Update checks and downloads contact GitHub. Remote services receive ordinary network-request information. The reviewed client has no integrated advertising or analytics SDK and does not automatically upload diagnostic logs or the installed-app selection.

Delete profiles and subscriptions in the app. Clear app storage or uninstall to remove remaining local settings and installation identifiers. For data held by your subscription provider, contact that provider. Support requests are handled through the Lucifer Connect GitHub project, where submissions may be public and GitHub's privacy policy applies. Do not submit credentials. The Russian sections above provide the full policy; this is a summary of the same practices.
