Создать обращение на GitHub ↗

Для создания обращения нужен аккаунт GitHub. Обращение будет публичным. Приложение можно использовать без аккаунта GitHub.

Что написать

  • Версию Lucifer Connect и систему: Android, Windows или Linux. Для Linux укажите дистрибутив и архитектуру x64/ARM64.
  • Что вы делали и какой результат ожидали.
  • Точный текст ошибки и шаги, после которых она возникает.
  • Для запроса по конфиденциальности — тему «Конфиденциальность Lucifer Connect». Для удаления — «Удаление данных Lucifer Connect».

Что не нужно публиковать

Не отправляйте ключи, пароли, адреса подписок, полные конфигурации, личные данные или снимки экрана с ними. Перед публикацией проверьте текст и вложения.

Установка на Linux

Выберите архив под x64 или ARM64, распакуйте его и выполните sudo ./install.sh. Для Ubuntu/Debian доступны пакеты .deb: установите загруженный пакет командой sudo apt install ./имя-файла.deb. Архив рассчитан на glibc; нужны PolicyKit, iproute2, nftables, util-linux и графические библиотеки. Приложение запускайте от обычного пользователя, повышение прав подтверждается отдельно при подключении.

Если ядро аварийно завершилось, блокировка сети остаётся включённой. Снимите её кнопкой питания или пунктом «Снять блокировку сети» в трее. Резервная команда: pkexec /opt/lucifer-connect/LuciferConnect --release-protection.

Быстрая помощь

  • Не добавляется подписка. Проверьте её срок действия у провайдера и используйте обычный HTTPS-адрес или поддерживаемую ссылку импорта.
  • Не устанавливается соединение. Убедитесь, что конфигурация актуальна. Доступность TCP-порта сама по себе не подтверждает успешную авторизацию и передачу данных.
  • Нужно очистить приложение. Используйте инструкцию по удалению данных.
  • Вопрос по оплате или аккаунту провайдера. Обратитесь к самому провайдеру подписки.
